# SALDO
## L5 Research Project - Budgeting App
- How can I make this cost free?
- Will this be able to compete with already existing budget applications out there?
- Can I ensure the privacy and security of user's data?

## Features

- User registration and login
- Add, edit amd delete expenses record
- Group transactions together in the same category
- Visualise data using charts 
- Local data storage
- Design responsive on both mobile and dektop
